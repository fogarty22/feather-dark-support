Feather Dark

A little help.

Start here to turn on the extension, choose a setting for a site, or report a problem.

Set it up

  1. Open Feather Dark after installing it.
  2. Open Safari Settings > Extensions and enable Feather Dark.
  3. Allow access to the websites you want it to darken.
  4. Click Feather Dark in Safari's toolbar to use its controls.

You can close the Feather Dark app after enabling the extension. To try it on a simple page, open the reading demo.

Choose a setting for a website

  • Automatic checks the page's background and leaves dark pages alone.
  • Always darken applies Feather Dark's stylesheet to that website.
  • Leave alone keeps that website's own appearance.

The main switch turns Feather Dark on or off. Your site choices are remembered locally.

A page isn't dark

Check that the extension is enabled, its main switch is on, and Safari has allowed it access to that website. Try Always darken for the site. Reload after changing the website's own theme.

Safari's own pages, PDFs, Reader mode, and embedded frames are outside the extension's scope. Some custom controls and background images may retain their original appearance.

A website looks wrong

Choose Leave alone for that website. Feather Dark uses a general stylesheet, so it cannot perfectly restyle every site.

Does it need to keep running?

You can close the Feather Dark app after setup. The extension has no background page, polling timers, page scans, or image processing. Safari still uses memory to run extensions and style pages.

Report a problem

Open a support issue

Include your macOS version, Safari version, the affected website, and which Feather Dark setting you selected. GitHub issues are public, so leave out passwords, account details, and private browsing information. A GitHub account is required to post.
